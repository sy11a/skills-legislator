## Confounds

1. **One law stamp for the whole run.** `v20-9dbb306-g22c1e5f` covers every
   scenario and every idempotency grade — no mixed-generation table.
2. **No law confound between the graded commit and HEAD.** `skill/` is
   byte-identical between `9dbb306` and HEAD.
3. **Same runner profile, model and Claude Code version as v19.** Both
   editions ran `claude` / `sonnet` / 2.1.241, which is what makes the
   185 → 194 comparison legitimate rather than an artifact of a harness or
   model change.
4. **The two baseline runs (Red baseline — part 2) each used a worktree at
   its own commit**, not the shipping checkout — `2153282` for
   fresh-scaffold-dotnet, `0147aef` for restructure — so each red is
   measured against exactly the law that predates its fix, nothing later.
5. **Timezone fragility in the fixture's commit dates, carried not fixed.**
   `commit_dated()` in `setup_workspace.py` writes timestamps with no UTC
   offset, so git reads them in machine-local time; a daylight-saving
   boundary between two fixture commits eats an hour, and the rotted
   fixture's debt interval measures 166 days on this machine where the
   brief predicted 167. No assert in this corpus reads a day count, only
   the slug and the document path, so nothing here flips on it — recorded
   so the next date-sensitive assert is written with an explicit offset.

## Defect chronicle

**No law defect and no grader defect was found by the corpus.** The two
defects this cycle produced were both found before the benchmark, by the
task reviews, and both were defects in the plan I wrote rather than in the
implementations:

1. The law described symbol anchors as resolving when the token "occurs
   literally", while the engine resolves a dotted token by its leading
   segment. The engine was right — requiring the full `Type.Member` string
   would produce the false positives the design was measured to avoid —
   so the law was amended to match (`687c137`).
2. The static rung stranded a reader whose repository has no `python3`,
   unlike every other conditional bullet in that file. Amended to name the
   situation without creating a loophole (`687c137`).

One defect was found by the implementer during Task 5 and escalated beyond
its fixture: the debt job fired on `codebase-map.md` through its `docs/`
anchor. Since that document backticks every top-level directory by design,
it would have been permanently in debt in every active repository, with no
owner action able to clear it — the systematic-noise class
`core/artifact-lifecycle.md` forbids. Directory anchors are now excluded
from the debt job and the law says so (`62ba335`, covered by `d40db9f`).

## Harness finding — a false-green path, worth its own case

The first corpus attempt (run `20260823-1716`) was discarded: I launched
`tools/evals-bg.sh` against a workspace that had never been materialized —
`evals/README.md` step 1 is `python3 evals/setup_workspace.py <ws>` and the
runner does not do it itself. Agents improvised in absent repositories,
grading refused for want of an `eval-base` tag, and two scenarios had no
`repo/` directory at all.

The waste is mine. The finding is the harness's: **that run reported
`upgrade` 21/21 CLEAN and `legacy-migration-agents-first` 22/22 CLEAN
against fixtures of unknown provenance, and nothing objected.** An hour of
agent runs was spent without any check that the workspace was
materialized. A precondition — every scenario directory holds a `repo/`
carrying an `eval-base` tag, else exit non-zero — turns an hour of waste
into an instant error and closes a path on which a benchmark can read
green while measuring nothing.
