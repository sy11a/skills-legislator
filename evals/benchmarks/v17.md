Four confounds, all of them real:

1. **Harness switch, mid-edition.** The zai plan hit its weekly limit with
   two scenarios unrun; the suite gained a second runner profile rather than
   waiting three days. A harness switch changes the system prompt, the tool
   set and the edit semantics — a **larger** confound than a model switch.
   Nothing in Phase 2 is comparable to v16.
2. **Model switch, twice** — glm-5-turbo → haiku → sonnet.
3. **Corpus change.** BL-036 minimized every trigger and added two
   scenarios; Phase 1's numbers are for a different corpus on different
   prompts.
4. **Grader change.** Six grader defects were fixed during the cycle, three
   of which had been passing falsely. Some Phase 1 greens were not earned.

`--safe-mode` is what makes harness B a fair instrument: no operator
CLAUDE.md, auto-memory, hooks, plugins, MCP or installed skills, so an
installed `legislator` cannot fire as a skill instead of being read as a
file. It is stricter than harness A, where the fixture's own entry document
was auto-injected.

## What the model floor is actually made of

haiku and sonnet split along one line, and it is worth expecting again:

- **Mechanical work — haiku is exact.** Byte-for-byte copies, the
  `profiles`→`stacks` key migration, stack removal, keep-list serialization,
  manifest ordering: 20/20, 15/15, 21/21.
- **Judgement — haiku substitutes something plausible.** restructure 23/30,
  audit 32/37. It proposed as fleet law exactly the three project-specific

So run a cheap model when cost matters, but **re-run every red on the floor
candidate before classifying it**: a red under a model that cannot do the
work carries no information about the law.

## What this cycle establishes

- **Idempotency is not a formality.** It found three defects the whole
  corpus had passed over. The general form: *a second run that writes is a
  first run that left work undone, or a law that permits two outcomes.* Any
  action classified by judgement rather than by repo state cannot be
  idempotent.
- **One fact, one place.** Four of the fifteen defects were the same shape —
  a fact derived twice, in two places, that drifted. Standing countermeasure
  is derivation (`selftest:derivation`); the general form is BL-038.
- **A missing assert is indistinguishable from a passing one.** Three
  greens were false. This is why `POLICY.md` now requires the assert to be
  designed with the change, not after it fails.
- **The suite outgrew the thing it tests.** Twelve of fifteen defects were
  in the suite or the harness. BL-039 proposes splitting it out.
