## What this edition establishes

- **A regex wall is only as complete as its last counter-example.** The
  `CLAUDE.md` row survived v18 because the hyphenated form of a right it
  already knew in two other spellings was not in the list. Nothing about
  the v18 design was wrong; the enumeration was incomplete, and an
  enumeration is never finished by inspection — only by the next miss.
- **A floor check is not a shape check.** `len(rows) >= 2 + 8` had been
  correct-looking since BL-038 and would have accepted a ninth artifact
  class silently, giving it no derived rights and no wall coverage. The
  matrix exists to make rights total; a parser that tolerates extra rows
  makes it partial again.
- **Stating a fact twice is a defect even when both copies are true
  today.** The `never-touch` bullet and `restructure.md` §2 agreed
  perfectly. The defect was structural: a third delegated class added to §2
  would have left SKILL.md silently stale.
- **Practice can be right while the vocabulary that licenses it is wrong.**
  `manifest × upgrade = replace` read literally licensed discarding `keep`;
  every run carried it forward correctly anyway, because Step 3 says so and
  an assert guards it. The carve-out closes the gap between what the law
  permits and what it means — the same hazard shape as v18's defect L2,
  found by reading rather than by a red.
