## The mutation pass earned its keep

The first pass was **206/212 — six survived**, and all six were one defect: the
stamp mutations still targeted `Emitted by docs/ai/engine.py report`, a string
this edition renamed. The mutation removed lines that were not there, the report
came back unchanged, and the assert passed — so six asserts about the emitter
stamp were **unfalsifiable** and would have stayed green forever while measuring
nothing. `grade.py`'s stamps were re-pointed in T-13 and `mutations.py`'s were
not; run history could never have shown it, because a healthy corpus is green
either way. Fixed (two lines), re-run: **212/212 killed, 0 survived, 0 uncovered,
0 unusable.**

## Baseline and confounds (named, per POLICY §9)

**The baseline is v24**, the last full measurement — v25 was partial (two
scenarios, no idempotency, no mutations) and ran on the profile default rather
than `sonnet`.

1. **The corpus lost a scenario and gained four asserts** (see the total above).
2. **The law renamed the instrument**, so every agent now calls `legislator
   <job>`. The first attempt of this benchmark measured that badly — see below.
3. **`audit` is 52/52 against v24's 48/48** on a fixture that changed: the
   `case-collisions` defect was planted mid-benchmark (T-14.1) after the meta
   assert reported it missing. Its 49/50 first measurement is recorded there.

## Two harness defects this benchmark found

**The arm was not on the scenario agent's `PATH`.** The first attempt died at
`fresh-scaffold-dotnet` 19/21 — a hand-ordered `ownedFiles` and a report with no
emitter stamp — because the agent tried `legislator version` once, found nothing,
and did the work by hand. From v26 the law names a binary; a harness that does
not put it in front of the agent measures the machine, not the edition.
`evals-bg.sh` now puts the published arm's directory on `PATH` for everything it
spawns. The same pass fixed `setup_workspace.py`, which still copied the deleted
`engine.py` into two fixtures and crashed setup outright.

**CI could not run the .NET suite**: `.github/workflows/dotnet.yml` called
`dotnet test src`, which discovers zero tests on this SDK (T-13.9). It runs
`sh evals/check_dotnet.sh` now.
