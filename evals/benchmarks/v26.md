**v26's floor is `sonnet` on the model-heavy scenarios and `haiku` on the
mechanical ones.** The split is clean and it is about one thing: the engine half
of a run is the binary's, and haiku drives it correctly — in
`fresh-scaffold-dotnet` the log shows `legislator detect`, `apply`, `verify`,
`report`, one call each, at exactly the four points `SKILL.md` names. What haiku
does not hold is the **model half**: `audit`'s three-step channel (perform checks
11/12 and the candidates scan → write them to a JSON file → run
`legislator audit --model-findings` and print its stdout verbatim) became a
hand-written `## Audit Summary` with appended prose and no candidates appendix;
`restructure` applied six of its own listed actions, left `.cursorrules`,
`UBIQUITOUS_LANGUAGE.md` and the stray rulebook on disk while reporting
"applied", and used its own section names instead of the pinned ones.

That is a model result, not a law result, and it was **shown** rather than
argued: the same law text, the same fixtures, the same arm, one model changed,
and every one of the eighteen haiku failures went green. A benchmark that had
stopped at the haiku numbers would have read as an edition regression.

## Baseline and confounds (named, per POLICY §9)

**The comparison is against v24, not v25** — v25 was a partial run (two
scenarios, no idempotency, no mutations), so the last full measurement is
`benchmarks/v24.md`. v24 ran on `sonnet`, which is what the right-hand column
above compares to.

1. **The corpus is smaller by one scenario.** `audit-engine-absent` is retired
   (T-13.10, the owner's ruling): it falsified check 15's engine-absent branch,
   which this edition deletes. A smaller total is arithmetic, not regression.
2. **The law renamed the instrument**, so every scenario's agent now calls
   `legislator <job>`. The first attempt of this run measured that badly and is
   recorded below.
3. **`audit` gained two checks with no fixture defect** — the one red.
4. **`restructure` measured 37 asserts under haiku and 38 under sonnet**: an
   assert whose subject the haiku run never produced cannot be measured, which
   is why its 23/37 is not "23/38".

## The first attempt, and why it was thrown away

The run was started once before at 20:25 and killed at 20:31 with
`fresh-scaffold-dotnet` at 19/21. Both failures — a hand-ordered `ownedFiles`
and a report with no emitter stamp — had one cause: **`legislator` was not on
`PATH`**, so the agent tried `legislator version` once and then did the work by
hand. From v26 the law names a binary; a harness that does not put it in front
of the scenario agent measures the machine, not the edition.
`tools/evals-bg.sh` now puts the published arm's directory on `PATH` for
everything it spawns, next to the two parity variables. The same pass fixed
`setup_workspace.py`, which still copied `skill/assets/engine/engine.py` into two
fixtures and crashed setup outright.
