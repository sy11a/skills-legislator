### Harness (1 hang + 2 notes)

- **The stall detector is fooled by a stream that emits keepalives without
  tool progress.** During Run B, `case-practice` sat for 7h20m on a
  `dotnet build` that never returned. The agent had no child process, but
  `run.jsonl` kept growing with keepalive frames and the repo's dirty count
  never changed — so the oracle (log growth + dirty-count freeze) judged it
  alive and never fired the resume ladder. Killed by hand; the runner moved
  on. The shipping run passed the same scenario in 23 minutes with no
  intervention, so this is an intermittent provider-side hang, but the
  oracle should not be satisfied by bytes alone: a stream that grows
  without a new tool call is not progress. Worth a backlog item against
  `tools/evals-bg.sh`.
- `--only`'s comment claims a targeted retest "keeps its run id", but
  `RUN_ID` is recomputed from the clock, so each retest opens a new run in
  `run.json`. Cosmetic, provenance-only.
- `status.md` accumulates across invocations, so a terminal line from an
  earlier invocation (`=== targeted run complete ===`) is
  indistinguishable from the current one when the file is polled by
  string. Poll `queue.json`, or count timeline events, not status strings.

## What this edition establishes

- **A table that is only prose is not enforceable; a table that is derived
  is.** Every one of the five fixes came from the grader reading the
  matrix, not from anyone reading the matrix. Two of them (Defects 2 and 3)
  were found by a *selftest over the law text* before any agent ran.
- **Naming a right creates the obligation to say who exercises it.**
  Defects 2 and 4 are the same shape: `never-touch` was written as if a
  mode's own hands were the only hands in the run. `heal` proved otherwise,
  and the vocabulary had to learn the word "delegated".
- **A closed vocabulary makes ambiguity visible instead of arguable.** The
  restructure run that refused to heal quoted the matrix at us. Under v17's
  scattered prose that same disagreement would have produced a plausible
  report and no red at all.
