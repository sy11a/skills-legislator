## BL-068 — the cross-platform audit (spike, tier 1)

Third case of the day, raised from the BL-064 review question. Two
clarifications set a maximal bar — Windows-native only (WSL is not an
answer) and the operator side on the same footing — and the bar changed
the findings' weight: the operator bash scripts break on macOS too
(`setsid`, GNU `stat -c`), not just Windows. The deadliest cells are both
silent and both environment-contract, not language: a `python3`-less
Windows leaves every hook failing with a non-2 exit (enforcement absent,
looking installed), and a symlink-less checkout turns `CLAUDE.md` into a
one-word text file so the constitution never loads. That criterion —
"a port pays only where the breakage lives in our runtime" — drives the
verdict: patch fleet-side (S set + launcher + the symlink design fork as
its own case), port the operator scripts off bash to Python, keep hooks
Python for per-call latency, and leave the engine's C# file-based option
open pending BL-069's dependency register. Also found riding along: the
engine reads every file with locale encoding (zero `encoding=`) — a
Windows mojibake bug worth fixing regardless of any OS plans. Process
note: PR #24 had been merged before the day's two spike-filing commits
landed on its branch, so BL-068/BL-069's backlog entries were stranded on
the merged branch — recovered by cherry-pick into this one. Dead ends:
none. Open: whether to file the symlink file-model case now or after
BL-069.

## ADR-0005 — the binary end state, decided and phased

The owner reviewed BL-068's verdict and pushed past it: the deterministic
part of the product should end as a universally executable binary on one
platform, not a set of scripts. Working through it corrected one audit
claim (the latency objection applied to `dotnet run`, not NativeAOT — in
compiled form .NET hooks are viable) and reframed the byte-verify
objection: byte-diff is the mechanism, not the goal, and a version-pinned
checksum-verified installed tool meets the same integrity goal. ADR-0005
records the decision (accepted): .NET/NativeAOT, machine-installed like
the hooks plugin, law stays text, opencode arm stays TS. The owner's
phasing is part of the decision: finish the existing fixes first —
BL-070 (the patch set) and BL-071 (the file-model fork) — so the scope is
measured, then BL-072 builds the arm on top, gated on BL-069. The audit
got an append-only addendum; its table stands unchanged.
