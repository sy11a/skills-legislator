## BL-077 — the outer-only pivot: brainstorm, spec, backlog re-cut

The owner opened the day with two ideas — the AI layer leaving the code
repository entirely, and the legislator as one installation per machine
configuring every project it will ever touch — and the session became the
design of edition v25. Decisions, all recorded in ADR-0007 and the spec's
clarifications: inner mode dies; the instance (a group of projects) is
the git unit; the code repo keeps zero tracked AI files; the machine
registry is the single truth about placement; kbl and fleet-obs become
modules, fleet-obs machine-wide with a *generated* registry plus a hand
overlay; config is code (which unblocked BL-067); default deterministic.
The link mechanism got a real critique: four candidates measured against
harness facts (Claude Code walks `CLAUDE.md` above `.git` but not rules;
opencode stops hard at the worktree; both attach an external config dir
by env — the M3 evolution that needs a CLI). Chosen: a two-file stub as
the channel, the global arms as sentinel, env-attach reserved. Dead end
noted: a clone inside the control tree — elegant, and opencode cannot
see it. Research went into the neighbours: kbl is pre-code with a fixed
canon; fleet-obs hardcodes the in-repo assumption in five places, hence
BL-080 must merge before v25. The backlog was revised: BL-027/044/045/
052/071 absorbed, BL-076 re-targeted to v26, BL-067 unblocked, new cases
BL-077…081, a new "Agreed order after v24". Side finding for the owner:
this machine's fleet-obs capture hooks point at the repository's
pre-rename path and have been silent since. Next: the plan package for
