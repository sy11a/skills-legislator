## changelog

- **The edition releases `linux-x64` alone** (ADR 0013, operator ruling 2026-09-23). `win-x64` had been red since BL-372 — four projects, 111 failures — so every matrix run on `master` finished red and stayed red, and a tag inherits that run. Development is Linux-only, so the three unexercised RIDs bought nothing and cost a permanent red. `released=(...)` in `tools/publish-legislator.sh` is now the single statement of the released set; `.github/workflows/dotnet.yml` builds it, and `evals/check_static.py` **reads that line** instead of restating the set, holding the two together in both directions — a released RID with no matrix row, and a matrix row the edition does not release ([ADR 0013](docs/adr/0013-the-edition-releases-linux-x64-alone.md)).

## journal

- Dead ends, in the order the round found them. **`released` as a build gate:** with one RID the publish script refused the host's own default RID on every macOS and Windows machine, which takes the arm, the .NET gate (it publishes after a green test run) and check 20's remedy from every non-Linux contributor in one act — while the README I had just written said the opposite. It is a statement about the release now; the toolchain's cross-OS refusal is the only fatal one. **Three parsers before one held**, each reading prose and calling it a fact: `rid not in body` was true of a comment saying nothing builds that RID; a regex over flow-style matrix rows reddened a green tree five ways and passed a matrix that builds nothing by moving the row under `exclude:`; and a regex over `released=(...)` read `#` and a runner name as released RIDs, on the shape someone restoring a RID would most naturally write. The workflow is `yaml.safe_load`ed and the array is read by bash — handed **only the assignment**, because my first version sourced the script, which runs it: it published a binary before the probe's own `printf` could run. Five more checks came from mutations that survived the earlier drafts, each a way the matrix can name a RID and build nothing. Open, and stated in the ADR rather than implied: nothing now verifies that the source still builds on Windows or macOS. That was already true in practice — the one RID with a builder was failing and the failure was being carried rather than read — but it is now true by decision, which is a different thing and belongs in the record.
