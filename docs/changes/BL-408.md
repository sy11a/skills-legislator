## changelog

- **The edition releases `linux-x64` alone** (ADR 0013, operator ruling 2026-09-23). `win-x64` had been red since BL-372 — four projects, 111 failures — so every matrix run on `master` finished red and stayed red, and a tag inherits that run. Development is Linux-only, so the three unexercised RIDs bought nothing and cost a permanent red. `released=(...)` in `tools/publish-legislator.sh` is now the single statement of the released set; `.github/workflows/dotnet.yml` builds it, and `evals/check_static.py` **reads that line** instead of restating the set, holding the two together in both directions — a released RID with no matrix row, and a matrix row the edition does not release ([ADR 0013](docs/adr/0013-the-edition-releases-linux-x64-alone.md)).

## journal

- Dead end, and the reason this case has two checks instead of one: the first draft kept the existing test's shape — `rid not in workflow_body` — and **both of its mutations survived**. The retired RIDs are named in the comment that explains why nothing builds them, so `"win-x64" in body` was true of a line saying win-x64 has no builder. A check that reads prose cannot tell a builder from a footnote; it now parses the matrix's own `include:` rows. Having written the parser, the inverse check was one line and worth having — a matrix row the edition does not release spends a runner and reddens a tag for nothing, which is exactly the state this case exists to end. Decision, with the reasoning: the retired rows stay in the workflow as a comment carrying each one's runner image and why `osx-x64` names `macos-15-intel` rather than the retired `macos-13` (BL-370), so restoring a RID is adding a row back rather than re-deriving what was lost. Open, and stated in the ADR rather than left implicit: nothing now verifies that the source still builds on Windows or macOS, and a regression there will not be seen until a RID is restored. That was already true in practice — the one RID with a builder was failing and the failure was being carried rather than read — but it is now true by decision, which is a different thing and belongs in the record.
