## changelog

- A freshly scaffolded repository no longer fails its own audit on the day it is created: the scaffold writes the day's journal entry recording the constitution it just laid, so `journal-recency` reads a day for the paths outside `docs/` that the scaffold itself commits ([BL-360](docs/cases/BL-360-scaffold-journal/summary.md), `sy11a/Architector#364`).

## journal

- Chose the entry over the exemption, and the reason is the reusable part: exempting the scaffold's own commit from check 8 is cheaper and leaves a new repository with an empty journal looking clean, but **the entry is true rather than filler** — a constitution was laid, at a named edition, with a named stack subscription — and it seeds the ritual, which is the harder half of a journal's adoption. A rule nobody has yet obeyed is a rule the first busy day drops. Said plainly rather than implied: **Step 4 is performed by the skill and not the engine**, so no test here can assert that a scaffolded repository passes its own audit; this repairs an instruction, and an instruction is followed by an agent — as the two runs that found the defect were doing. Caught on the way in: `check_static.py` failed on five absolute local paths in BL-357's refutation files, merged because that case ran the .NET gate on its last commit and not the static one. Redacted under `records.md`'s own carve-out, which makes redacting identifiers lawful where rewriting a decision is not. **A gate is only as good as the last commit it ran on.**
