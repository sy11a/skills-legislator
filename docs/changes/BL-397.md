## changelog

- **Edition v27: the retirement and the declaration move in one act.** Edition 26 retires `docs/ai/engine.py`, and four governed repositories declare that file as their own gate — in hand-authored instance data the legislator owns nothing of, foundry's in `tools/gate.sh` rather than prose. The day any of them upgraded was the day its declared gate named a file that is gone. `apply` now sweeps, before its first write, for commands naming a path **this run is about to retire**: it rewrites the declaration homes — the entry document, `.claude/rules/**`, the scripts under `tools/` the repository owns — from `python3 <retired> <job>` to `legislator <job>`, in place; it **stops the run at exit 4** on a shape it does not recognise, naming the file and the line, with the retirement not performed either; and it reports rather than rewrites a case summary, a journal day or a changelog entry naming the same command, because those record what was true when they were written. The rule keys on what the run retires, not on `engine.py`, so a later edition retiring something else is covered by the same act ([BL-397](docs/cases/BL-397-the-upgrade-moves-the-declaration/spec.md), `#60`, `sy11a/Architector#448`).

## journal

- The decision was the whole case: `sy11a/Architector#448` left open *"whether legislator's own migration should perform that rewrite"*, and the alternative it was weighed against is a standing order that a human performs both acts together — which is the class of unenforced law this fleet has spent the week repairing. Ruled: the migration does it, because the edition knows what it stopped delivering and the repository does not. Dead end worth recording, from before this case: moving clerk's declaration **ahead** of its upgrade was tried and refused by its own refutation round — it adds a binary the repository tells no contributor to install, and it makes the entry document contradict the edition-25 law it imports. Both orderings are traps; that is why the two acts had to become one. Open, and deliberately not taken here: the four repositories take edition 27 on the operator's ordering, one at a time or at once, and the standing order in `#448` lifts as each does.
