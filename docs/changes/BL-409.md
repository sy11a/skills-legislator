## changelog

- **The fragment home's own README is no longer read as a fragment, and it no longer contradicts the law it explains** (`#53`). `FragmentLint` enumerated `docs/changes/*.md` and applied the fragment shape to all of them, so a repository went red the moment it scaffolded the home correctly and could not clear the finding without deleting its own README; the name is the gate now — a file is a fragment when it is named for a case key, and a case-named file must declare that case, which also catches a fragment filed under someone else's key. The delivered template told authors to write `## okf-log` and a free-form changelog, which the same edition's `core/changelog.md` had already made optional and one-bullet ([BL-409](docs/cases/BL-409-the-fragment-home-explains-itself/summary.md)). It cleared one of the two findings that scenario carried; the other — the eval fixture's `## Unreleased` heading missing its brackets — is BL-406's, and only both together make it 8/8.

## journal

- Decision, with the reasoning: the gate is the file's **name**, not a by-name skip of `README.md`. Skipping the README by name would have closed the reported symptom and left the home's next piece of furniture — a note, a scratch file — to redden the same way; and it would have thrown away the half of the fix that pays, since the name is also what ties a fragment to its case. `legislator render` inserts by case key, so a fragment named for one case and declaring another lands in the wrong place with nothing to say so. `#53` itself offered both directions and called this the stronger one. Open, and deliberately not folded in: `#51` is the same lint's other standing finding — it demands that every *pending* fragment match the current branch, while fragments accumulate until a release cut, so every branch reddens on every other case's fragment. Same class and same function, but a separate intent, and unlike this one it does not redden the corpus. Worth noting for whoever takes it: this case was forced by a benchmark scenario asserting the **delivered** engine, which is why the arm had to be republished from the branch before the scenario could see the repair — a fix in `src/` that nobody publishes is invisible to the thing that found it.
