## changelog

- **The grader reads a Step 4 row whole.** BL-360 marked `docs/journal/<today>.md` **Fresh-scaffold mode only** on 2026-09-20 and `evals/grade.py` was not told, so `upgrade` and both migrations asserted a file the law forbids them to write — and the target's `<today>` was never resolved either, making the assertion unsatisfiable in *every* mode including the one that owes the file. Both were latent from that one commit and neither was observed, because no benchmark ran between BL-360 and the run that measured edition 27. `scaffold_artifacts(mode)` now reads the notes column, `_resolve_today()` substitutes the day and raises on a placeholder it cannot resolve, and the mode reaches `scaffold_checks`. Added with it: the assertion BL-360 legislated and nothing measured — an upgrade or a migration must not *write* a reserved target, since a presence-only assert cannot tell obedience from the absence of the act ([BL-406](docs/cases/BL-406-the-grader-reads-the-mode/summary.md)).

## journal

- Decision, with the reasoning: the derivation reads the law's own words rather than gaining a structured mode column in `SKILL.md`. A column would be cleaner to parse and would be a behavioral change to the shipped skill — bytes in every governed repository's owned files, and a full benchmark to land a parser convenience. Reading the third column is also the act the second column already performs for `(empty directory)`, so the shape has precedent in the same function. Dead end: emitting the new "wrote a reserved target" assert in every mode. In `scaffold` the reserved rows are owed, so the question has one possible answer — an assert that cannot fail, which reports coverage it does not have; it is now emitted only where the law actually withholds something from the mode. Open for the next session, and filed rather than folded in: `audit_slugs_derived` is red on `origin/master` and was before this branch — 22 audit checks carry a severity and 21 carry a pinned slug, `Bindings form` (BL-357) having gained the first without the second. Same class as this case. Its check also prints its success message on failure, which is why a standing red reads as a pass to anyone who runs the self-test.
