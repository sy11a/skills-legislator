## changelog

- **The grader reads a Step 4 row whole, and asks what the run did rather than what day it is.** BL-360 marked `docs/journal/<today>.md` fresh-scaffold-only on 2026-09-20 and `evals/grade.py` was not told, so an upgrade was asked for a file the law withholds from it — and the target's `<today>` was never resolved either, making the assertion unsatisfiable in *every* mode including the one that owes the file. Neither was observed because no scenario asserting Step 4 was graded between that commit and the run measuring edition 27. `scaffold_artifacts(mode)` now reads the notes column, `_resolve_today()` substitutes the day without raising a scenario away, and `day_files_this_run_added()` reads the run's own trace so a day file dated any other day is no longer invisible. Added with it: the assertion BL-360 legislated and nothing measured — an upgrade must not *write* a withheld target — carried by both upgrade scenarios, and `selftest:derivation` promoted to a stage-1 gate, since it held real controls and ran nowhere the benchmark ran ([BL-406](docs/cases/BL-406-the-grader-reads-the-mode/summary.md), `#63`).

## journal

- Decision, with the reasoning: the derivation reads the law's own words rather than gaining a structured mode column in `SKILL.md` — a column would parse more cleanly and would be a behavioral change to the shipped skill, bytes in every governed repository's owned files and a full benchmark to land a parser convenience. Reading the third column is also the act the second already performs for `(empty directory)`. Dead ends, both found by the round rather than by me: keying the new assert to `date.today()`, which made it blind to a day file written on any other day and turned a re-grade the next morning into a false red; and raising on an unresolvable placeholder, which converts a one-assert finding into a lost scenario, because nothing in `main()` wraps a scenario grader. A third was mine alone — a slice replace between two indices that swallowed the function defined between them, caught only because the module then failed to import. Open, and filed as `#64` rather than folded in: check 22 carries a severity and no pinned slug, the engine emits it at `Critical` where the law says `Warning`, and `audit_slugs_derived` passes one evidence string for both outcomes so its standing red prints the success sentence. The operator ruled the day-file contradiction on 2026-09-23 — the File authority table governs and the prohibition is the upgrade's — which settles what the grader encodes but not what `SKILL.md` should say; the heading's overreach is still there to repair.
