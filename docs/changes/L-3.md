## changelog

- Change fragments replace hand-edited views: a case adds one `docs/changes/<case>.md` and `legislator render` writes `CHANGELOG.md`'s `[Unreleased]` section, `docs/okf/log.md` and `docs/journal/` from it, idempotently by case key, with `sdd-lint` checking fragment shape ([L-3](docs/cases/L-3-change-fragments/summary.md)).

## okf-log

- Added `ChangeFragment` — the one-fragment-per-case artifact under `docs/changes/` with YAML front matter (`case`, `issue`, `kind`, `date`) and three sections (`## changelog`, `## okf-log`, `## journal`). A branch adds one; `legislator render` assembles the three views.
- Added `RenderJob` — the engine job behind `legislator render`: reads fragments, validates front matter, renders `CHANGELOG.md`'s `[Unreleased]`, `docs/okf/log.md` and `docs/journal/YYYY-MM-DD.md` idempotently by case key. Refuses malformed fragments and task-branch execution.
- Added `FragmentLint` — the `sdd-lint` pass that checks fragments (front matter present, kind in the closed set, case matching branch) where it used to check the `[Unreleased]` section by hand.
- Added `ChangesDir` to `LegislatorOptions` and `Changes` to `RepoLayout`.
- Updated three fleet core rules for the fragment model: `changelog.md`, `dev-journal.md`, `okf.md`.

## journal

- Implemented change fragments and rendered views (L-3, Architector #327): `legislator render` reads `docs/changes/*.md` fragments and writes the three views — `CHANGELOG.md`'s `[Unreleased]` section, `docs/okf/log.md`, and `docs/journal/YYYY-MM-DD.md` — idempotently by case key. A task branch adds one fragment and never edits the views directly; running `render` on a task branch is refused. Three fleet rules rewritten for the fragment model: `core/changelog.md`, `core/dev-journal.md`, `core/okf.md`. `sdd-lint` now checks fragment shape (front matter, kind, case-branch match) where it checked the `[Unreleased]` section by hand. Engine job at `src/Legislator.Engine/Jobs/RenderJob.cs`, registered in `JobRegistry.cs`; fragment lint at `src/Legislator.Engine/Sdd/FragmentLint.cs`; committed fixture pair in tests.
